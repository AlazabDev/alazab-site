## ⚡ ابدأ في 5 دقائق | Get Started in 5 Minutes

### 1. الوصول للحاسبة
```
اذهب إلى: http://localhost:3000/cost-calculator
أو / Go to:
```

### 2. أدخل معلومات المشروع
- اسم المشروع
- نوع المشروع (سكني، تجاري، إلخ)
- المساحة بالمتر المربع
- نوع التشطيب
- الموقع

### 3. ستحصل على النتيجة فوراً
- المواد
- العمالة
- التشطيبات
- الإجمالي الكلي

### 4. حفظ أو تنزيل
- اضغط "حفظ العرض" لحفظ في قاعدة البيانات
- اضغط "تنزيل" لتحميل التقرير
- اضغط "طباعة" للطباعة المباشرة

---

## 📋 خطوات سريعة | Quick Steps

### إضافة عناصر مخصصة
1. اذهب لتبويب "العناصر"
2. أدخل اسم البند
3. اختر الفئة
4. أدخل الكمية والسعر
5. اضغط "إضافة عنصر"

### مقارنة عرضين
```
لتفعيل المقارنات:
1. احفظ عرضين
2. اذهب إلى صفحة المقارنات
3. اختر العرضين
4. شاهد الفروقات
```

### قائمة العروض
```
اذهب إلى: /cost-estimates
لترى جميع العروض المحفوظة
```

## ❓ الأسئلة الشائعة | FAQ

**س: هل يتم حفظ العروض تلقائياً؟**
ج: لا، اضغط "حفظ العرض" يدويًا

**س: هل أستطيع تعديل عرض بعد حفظه؟**
ج: نعم، من قائمة العروض

**س: كيف أطبع التقرير؟**
ج: اضغط "طباعة" أو استخدم Ctrl+P

**س: هل الأرقام بالجنيه المصري فقط؟**
ج: نعم، حالياً الجنيه المصري (₪) فقط
