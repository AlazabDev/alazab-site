# خدمات مكافحة الآفات

**الاسم الإنجليزي:** Pest Control Services

**التصنيف التشغيلي:** النظافة والصحة التشغيلية

## وصف الخدمة

مكافحة الآفات خدمة ضرورية للمطاعم والمقاهي والمخازن والفروع التجارية، لأنها تؤثر على الصحة العامة، سمعة العلامة التجارية، سلامة المخزون، والامتثال لمعايير التشغيل. ظهور حشرات أو قوارض داخل الموقع لا يعد مشكلة نظافة فقط، بل مؤشر خطر قد يسبب شكاوى العملاء أو إغلاقًا مؤقتًا أو تلفًا للمواد.

تقدم UberFix / العزب خدمات مكافحة الآفات ضمن إطار منظم يشمل الفحص، تحديد مصدر الإصابة، المعالجة المناسبة، إغلاق نقاط الدخول، وتقديم توصيات للوقاية. الخدمة مناسبة للتدخل العاجل عند ظهور مشكلة، أو كصيانة دورية للفروع التي تتعامل مع أغذية أو مخازن أو مناطق خدمة.

## ما هي هذه الخدمة؟

خدمة مكافحة الآفات تشمل التعامل مع الحشرات الزاحفة والطائرة والقوارض ومصادر الإصابة داخل المنشآت التجارية. قد تشمل المعالجة استخدام مواد مناسبة، مصائد، سد فتحات، تنظيف مناطق جذب، وفحص أماكن التخزين والصرف والمداخل. يتم تنفيذ الخدمة مع مراعاة سلامة العملاء والموظفين وطبيعة النشاط.

## متى تحتاج المنشأة إلى هذه الخدمة؟

- ظهور حشرات داخل الفرع أو المطبخ أو المخزن.
- رؤية آثار قوارض أو تلف في عبوات أو أسلاك.
- وجود روائح أو مخلفات أو حركة غير طبيعية.
- قبل تفتيش صحي أو بعد شكوى عميل.
- الصيانة الدورية للمطاعم والمخازن.
- بعد أعمال صيانة فتحت مسارات دخول جديدة.

## نطاق الأعمال

- فحص الموقع وتحديد نوع الآفة ومصدرها.
- معالجة الحشرات أو القوارض حسب الحالة.
- تركيب أو فحص مصائد عند الحاجة.
- تحديد نقاط الدخول مثل فتحات أو صرف أو أبواب.
- تقديم توصيات تنظيف وتخزين وسد فتحات.
- تحديد جدول متابعة إذا كانت الإصابة متكررة.
- توثيق الملاحظات للفرع أو الإدارة.

## كيف تعمل الخدمة داخل UberFix / العزب؟

1. استلام البلاغ مع تحديد نوع الآفة ومكانها.
2. تقييم حساسية الموقع: مطعم، مخزن، منطقة عملاء.
3. تحديد موعد مناسب لتقليل التعرض للعملاء.
4. تنفيذ المعالجة والفحص.
5. تسجيل نقاط الضعف ومصادر الجذب.
6. متابعة النتيجة وتحديد الحاجة لجولة إضافية.

## بيانات يجب جمعها من العميل

- نوع الآفة إن أمكن: صراصير، نمل، ذباب، قوارض.
- مكان الظهور داخل الموقع.
- صور أو وصف للآثار.
- هل يوجد مطبخ أو مخزن أغذية؟
- هل المشكلة متكررة أم أول مرة؟
- أفضل وقت للتنفيذ خارج ساعات الذروة.

- نمل

## حدود الخدمة

يجب الالتزام بتعليمات السلامة بعد المعالجة، خصوصًا في أماكن الأغذية. لا تكفي المعالجة الكيميائية وحدها إذا استمرت مصادر الجذب مثل مخلفات الطعام أو فتحات الدخول أو سوء التخزين.

## النتيجة المتوقعة

النتيجة المتوقعة هي تقليل أو إزالة الإصابة الحالية، تحديد أسبابها، ووضع إجراءات وقائية تمنع تكرارها داخل الموقع.

## ملاحظات تشغيلية

يجب على النظام عدم طلب بيانات ذكرها العميل بالفعل في رسالته. إذا قال العميل اسم الفرع أو نوع العطل أو العنصر المتضرر، يتم التقاط هذه البيانات مباشرة وربطها بالطلب. الأسئلة التالية يجب أن تكون فقط لاستكمال النواقص المؤثرة على التنفيذ مثل الصور، درجة الخطورة، وقت الزيارة، وهل الموقع يعمل أم متوقف.
