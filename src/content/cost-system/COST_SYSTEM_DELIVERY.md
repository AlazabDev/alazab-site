## 🎯 المميزات الرئيسية | Key Features

### 1. حاسبة متقدمة
- حساب تكاليف بمعادلات معقدة
- دعم أنواع مشاريع متعددة (سكني، تجاري، صناعي، تجديد، تجارة التجزئة)
- معاملات حسب نوع التشطيب (بسيط، عادي، فاخر، متميز)
- معاملات حسب الموقع
- إضافة عناصر مخصصة
- حساب فوري للتكاليف

### 2. تقارير احترافية
- تقرير HTML بتصميم احترافي
- دعم كامل للعربية (RTL)
- رسوم توضيحية للتكاليف
- توزيع النسب
- تقرير نصي بسيط
- بيانات CSV للجداول

### 3. مقارنات متقدمة
- مقارنة عرضين سهلة
- عرض الفروقات بصرياً
- رموز مؤشرات (trending up/down)
- ملخص المقارنة

### 4. إدارة البيانات
- حفظ دائم في Supabase
- عرض قائمة العروض
- تعديل العروض
- حذف العروض
- استيراد/تصدير JSON

### 5. دعم عربي شامل
- واجهة عربية كاملة
- تقارير بالعربية
- ترقيم عربي
- صيغة RTL
