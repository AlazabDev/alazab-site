# التسجيل المضمّن لواتساب

الصفحة: `/whatsapp-connect`، محمية بصلاحيات إدارة الموقع.
تستخدم Facebook SDK الموجود في `index.html` دون تحميل نسخة ثانية.

- App ID: `1061494059972503`
- Login configuration: `1815526366103718`
- Embedded Signup: `v4`
- تبادل الرمز: `POST /api/meta/embedded-signup/complete`
- ترتيب وصول رمز الدخول وحدث FINISH غير مفترض؛ تنتظر الصفحة كليهما.
- تُحفظ معرّفات الجلسة فقط في sessionStorage؛ لا يُحفظ الرمز أو مفتاح الإدارة فيه.

## تجهيز الخادم

1. طبّق `server/sql/whatsapp-embedded-connections.sql` على قاعدة PostgreSQL المستخدمة في `server/db.js`.
2. اضبط متغيرات بيئة الخادم:
   - `META_APP_ID=1061494059972503`
   - `META_APP_SECRET`: سر التطبيق نفسه.
   - `META_TOKEN_ENCRYPTION_KEY`: مفتاح عشوائي 32 بايت ممثل في 64 حرف hex (يمكن توليده بـ `openssl rand -hex 32`). احتفظ بنفس المفتاح لفك تشفير الرموز لاحقًا.
   - `META_ADMIN_API_KEY` أو `ADMIN_API_KEY`: مفتاح إدارة المسار الموجود. يُدخله المسؤول في الصفحة عند الربط.
3. أعد تشغيل Express. افتراضيًا تتصل الصفحة بـ `https://alazab.com/api/meta`؛ يمكن تغيير الأساس عبر `VITE_META_API_URL`.
4. في إعدادات تطبيق Meta، تحقق من إضافة نطاق الموقع وتهيئة Facebook Login for Business والتكوين المحدد للموقع الإنتاجي.

## الاختبار

افتح الصفحة بحساب مدير، وأدخل مفتاح إدارة Meta ثم أكمل رحلة Facebook.
يجب ظهور WABA ID وPhone Number ID بعد تأكيد Meta ملكية الهاتف للحساب وحفظ الرمز مشفرًا.
الإلغاء لا يرسل طلب تبادل؛ لا يُرسل طلب التبادل قبل وصول الرمز والمعرّفات معًا.

هذه الإضافة لا تغيّر اشتراكات webhooks الحالية ولا تسجل الهاتف مجددًا ولا تعدّل الدفع.
نجاح الصفحة يعني نجاح مبادلة الرمز والتحقق من ارتباط الهاتف وحفظ الربط؛ اختبار إرسال واستقبال الرسائل خطوة مستقلة.
